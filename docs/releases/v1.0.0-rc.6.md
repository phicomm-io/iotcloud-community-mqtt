# IoTCloud 1.0.0 RC6

新增大金带屏幕 G3（BRY88BBA15G）的设备控制和屏幕设置，支持布局、主题、天气、提醒、亮度、恢复服务与在线更新。G3 保留 `daikin` 设备协议模型，按硬件型号区分界面；账户绑定、ACL 和二进制 MQTT 中继继续共用现有机制。

公共前端同步更新插座自动化、列表功率刷新以及 G3 屏幕和设备演示。屏幕 MCU 大文件安装目前需要在局域网直接访问设备；云端支持屏幕控制和 ESP32 在线升级。

本版使用固定的前端来源和多架构镜像摘要发布。部署时保留地区各自的账户、绑定与 broker 数据。

Adds device controls and screen settings for the Daikin G3 display model (BRY88BBA15G): layout, themes, weather, reminders, brightness, recovery services and online updates. G3 retains the `daikin` wire model and selects its interface by hardware identity, reusing account ownership, ACLs and binary MQTT relay.

The shared frontend also updates socket automation, device-list power refresh and G3 screen/device demos. Large screen MCU uploads require direct LAN access; cloud access supports screen controls and ESP32 online updates.

The release pins its frontend source and multi-architecture image digests. Deployments preserve each region's account, device binding and broker data.
