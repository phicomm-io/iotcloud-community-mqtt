# v1.0.0-rc

IoTCloud v1.0.0 候选版，配套社区设备固件与新版 WebUI。

- 设备管理、账户页面和本地连接支持简体中文与 English，延续原有界面风格。本地连接由按钮展开设备 IP 和密码。
- 新用户名与 MQTT 别名统一为 3–32 个 ASCII 字母、数字、下划线、点或连字符。已有长账号保留登录，可添加短 MQTT 别名；邮箱登录独立处理。
- M1 的甲醛、PM2.5 两个显示区域可独立配置来源、数字格式、字样、单位和九段色灯；支持本机与其他在线传感器、TC1 功率、大金数据、A1 风机输出百分比及 API 原样写入，双击整体切换原始 / 用户读数。需配套支持相应能力的联网固件及 M1 传感器 MCU。
- 连接大金中枢版时可管理本地账户、MQTT Broker、上游事件与巴法云转发，以及可选的实验性 HomeKit HAP 桥接。局域网设备和 Home Assistant 可直接连接中枢。
- Release 附带的 `release-manifest.json` 记录准确源码、前端与协议锁，以及 amd64 / arm64 后端和网页镜像 digest。候选版镜像使用 `v1.0.0-rc` 标签，保留原有 `latest`。

镜像：`ghcr.io/phicomm-io/iotcloud-community-mqtt-backend:v1.0.0-rc`、`ghcr.io/phicomm-io/iotcloud-community-mqtt-web:v1.0.0-rc`。部署方式见仓库运维说明；升级时保留配置和数据。

[按设备查看文档](https://phicomm-io.github.io/) · [开发者接口与协议](https://phicomm-io.github.io/iotcloud-community-protocols/)

## English

This release candidate pairs IoTCloud with the community device firmware and updated WebUI.

- Chinese and English account, device and local connection pages retain the existing design. A button expands the local IP and password fields.
- New usernames and MQTT aliases use 3–32 ASCII letters, digits, underscores, dots or hyphens. Existing long accounts can still log in and add a short MQTT alias; email login remains separate.
- Configure both M1 display areas independently, including source, number format, original labels, units and nine lamp segments. Sources include local and online sensors, TC1 power, Daikin readings, A1 fan output percentage and direct API values. Double press switches both areas together. Compatible Wi-Fi and sensor MCU firmware is required.
- The Daikin hub variant provides local accounts, an MQTT Broker, upstream and Bemfa forwarding, and optional experimental HomeKit HAP bridging. LAN devices and Home Assistant can connect directly.
- `release-manifest.json` binds the source, frontend and protocol pins to the amd64 / arm64 image digests. Candidate images use the exact `v1.0.0-rc` tag and preserve `latest`.

Follow the repository operations guide and retain configuration and data during upgrades.
