# v1.0.0-rc.5

修复 IotCloud 设备列表的数据刷新与 S30 计量显示。

- M1 持续解析设备状态上报，未选中时也能更新空气质量、CO₂ 和气压；兼容直接负载与 API 包装格式，并保留能力身份校验。
- S30 显示真实有功功率，避免把继电器开关值显示为 1 W。功率独立轮询，按字段有效位显示电压、电流；数据过期时清空读数，恢复后继续刷新。
- 修复 S30 访问统计请求返回 400 的问题。包含插座定时与功率自动化界面。
- Release 的 `release-manifest.json` 固定源码、前端锁与两个多架构镜像 digest。候选版镜像使用精确标签 `v1.0.0-rc.5`，不修改 `latest`。

这是平台版本；升级平台无需重刷设备固件。部署时保留原有配置、账号、设备登记及 Broker 数据，按仓库运维说明拉取 CI 发布的镜像。

## English

Fix device-list freshness and S30 metering in IotCloud.

- Parse both direct and API-wrapped business publications so unselected M1 cards keep receiving air-quality, CO₂ and pressure readings. Capability identity validation remains enforced.
- Use measured S30 active power instead of the relay boolean. Poll power independently, honor voltage/current validity bits, and clear stale readings until fresh data returns.
- Accept S30 device-view analytics instead of returning HTTP 400. Includes socket schedule and power automation controls.
- The release manifest pins source, frontend and both multi-architecture image digests. Candidate images use `v1.0.0-rc.5` and preserve `latest`.

This is a platform release and requires no device firmware update. Retain existing configuration, accounts, device registrations and Broker data when deploying the CI-published images.
